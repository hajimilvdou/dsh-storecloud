## U1. 取消负载均衡：隔离与双侧提醒

### U1.1 管理员侧操作
管理端「联邦互联」页对 LB 成员执行「退出负载均衡」：
- 停止实时通道 → 双方数据**冻结为最后一致快照** → 相互标记为独立源；
- 之后的共享范围回落到**联邦勾选配置**（v3.3 F3 矩阵），不再全量互通；
- **凭证互认立即取消**（LB 内免密/登录保持的前提消失）。

### U1.2 用户端提醒（进入 LB 提醒，退出也提醒）
| 时机 | 客户端通知（"源与系统"类） |
|---|---|
| 加入 LB | 已有：「发现负载均衡源 X，免密加入」（v3.4 M2） |
| **退出 LB** | 「mirror-01.cn 已退出与本源的负载均衡，现为**独立源**：① 你在原集群的数据保留在原集群；② 切换到它 = 切换到独立源（自动登出 GitHub，首次询问是否同步本地数据）；③ 备用源列表已自动更新。」 |

退出后该源完全按 v3.4 独立源方案对待（换源状态机场景①）。

## U2. 混合版本集群：能不能实现、如何回滚、回滚后共享适配

### U2.1 能不能实现版本不统一？—— **能，靠三条协议纪律**

| 纪律 | 内容 |
|---|---|
| **协议版本协商** | 联邦/集群通信双方握手时交换 `protocol_version`，**全程按较低版本通信**（min 原则） |
| **未知字段忽略** | 所有同步消息允许未知字段：低版本节点收到高版本的新字段/新对象类型 → 忽略或"暂存待升级后生效"，**绝不报错** |
| **功能降级矩阵** | 高版本特性对低版本节点自动隐藏/降级（如新版对象类型不推送给旧节点） |

由此支持**滚动升级**：集群逐台升，升级期间混合版本正常工作，用户无感。

### U2.2 如何回滚
1. **应用**：切回旧镜像（秒级，v3.5 D3）；
2. **数据库**：expand-contract 纪律——"收缩"类迁移（删列/删表）**必须延迟一个版本周期**才允许执行，保证回滚后旧代码仍能读当前库；
3. **顺序**：集群内逐台回滚，同一时刻最多一台在变更。

### U2.3 回滚后的共享适配
- 回滚方重启后**重新握手** → 协议版本自动降级回双方 min 值；
- 回滚期间错过/暂存的高版本数据：按副本版本向量**增量追平校验**；无法识别的对象保持"暂存"，待下次升级后生效；
- 回滚方若为某对象的 home 服：权威数据不受影响，联邦副本按其版本重新对齐；
- 版本差异超过兼容窗口（`protocol_window`，默认 2 个 minor 版本）→ 拒绝互联并告警管理员，防止"老到无法对话"的节点污染数据。

## U3. 账号注销

### U3.1 入口与流程
客户端「我的 → 设置 → 注销账号」（管理端也可代执行）：
```
展示影响说明 → 二次确认（输入当前用户名）→ 执行 → 确认完成
```

### U3.2 数据处理矩阵

| 数据 | 处理 |
|---|---|
| 账号记录（github_id/login/姓名） | **删除** |
| 云端安装清单、点赞、订阅、上报记录 | **删除/匿名化**（点赞计数同步回退） |
| 已发布的组 | 用户二选一：**删除**，或**匿名保留**（作者显示"已注销用户"，组内容不变） |
| 审计日志 | 只留"某账号于 X 时注销"事件，**不留个人信息** |

### U3.3 联邦传播
注销在 home 服执行后：联邦凭证立即失效；各联邦服按 home 权威更新该用户的跨服互动计数；LB 集群内实时生效。

## U4. 密钥轮换（按指示取消）

- 不做自动轮换流程；保留**手动改配置 + 重启**的更换能力（访问密码、联邦密码、token 池均可手动更换）；
- 风险登记：JWT secret 长期不换属已知接受项，泄露时处置 = 手动更换 + 全员会话失效。

## U5. 时钟同步方案

1. **容器不改时间**：Docker 容器共享宿主机时钟 → 关键是**宿主机开 NTP**（chrony 或 systemd-timesyncd，部署文档注明必装）；
2. **应用自检**：服务启动 + 每小时，比对本机时钟与可信源（NTP / HTTPS 响应 Date 头）：
   - 漂移 > 500ms → 监控页告警；
   - 漂移 > 5s → **拒绝签发时间敏感凭证**（JWT/签名），防止签出即过期或永不失效的票据；
3. **容忍窗口**：JWT 与时间戳校验允许 ±60s clock skew（防边缘抖动误伤）；
4. 监控页「服务健康」显示当前时钟漂移值。

## U6. 施工准备与验收测试清单（供执行 agent 使用）

### U6.1 需要人工注册/提供的凭据

> **执行约定**：执行 agent 进行到依赖某项凭据的步骤时，**自动暂停并向用户索取**，不得留空或造假。

| # | 凭据 | 在哪注册/获取 | 用途 | 需要时机 |
|---|---|---|---|---|
| 1 | GitHub Personal Access Token ×3 | GitHub → Settings → Developer settings → PAT | 抓取 token 池 | P0 服务端联调时 |
| 2 | GitHub OAuth App（Client ID/Secret） | GitHub → Developer settings → OAuth Apps（回调地址填服务器域名） | 用户登录 | P1 登录功能联调时 |
| 3 | LLM API Key（DeepSeek 或兼容端点） | 对应平台 | 翻译插槽（当前默认关） | P2 才需要 |
| 4 | 告警 Webhook（飞书/钉钉群机器人地址） | 对应 IM 群设置 | 监控告警 | P1 监控联调时 |
| 5 | 域名 + TLS 证书（Caddy 可自动签） | 域名服务商 | 对外服务 | 上线前 |
| 6 | 对象存储桶（备份用） | 云厂商 | 每日备份 | 上线前 |

### U6.2 验收测试清单（自动执行，通过标准即验收线）

| # | 测试 | 方法 | 通过标准 |
|---|---|---|---|
| T1 | 迁移与启动 | 空库 `compose up` → 再跑一次 migrate | 服务健康；重复 migrate 幂等无副作用 |
| T2 | 限流阈值压测 | k6/自写脚本对读写接口梯度加压 | 正常峰值 3~5 倍不 5xx；超限返回 429 且不误伤正常流量 → 回填阈值到配置 |
| T3 | 降级测试 | kill 服务端进程 | 客户端进离线模式：可搜索/浏览本地缓存，dsh 本体不受影响 |
| T4 | 联邦一致性 | 双节点互联，A 建组/拉黑 | B 端秒级可见；断开后墓碑正确传播 |
| T5 | LB 无感切换 | kill 主节点 | 客户端 ≤30s 自动切到健康节点，登录保持、数据无差别、无同步弹窗 |
| T6 | LB 退出隔离 | 管理端执行退出 LB | 凭证互认取消；客户端收到"退出提醒"；该源按独立源对待 |
| T7 | 混合版本 | 一节点高版本、一节点低版本互联 | 按 min 协议通信；新字段被忽略不报错；超窗拒绝互联并告警 |
| T8 | 回滚 | 升级后切回旧镜像 | 服务正常；共享数据对齐；DB 无需回退 |
| T9 | 安全管线 | 构造投毒样本包（含恶意 postinstall/混淆代码/已知漏洞依赖） | L1/L2 全部命中；拉黑后客户端安装被拦截 |
| T10 | 时钟 | 人为注入时钟偏移 | >500ms 告警出现；>5s 拒签凭证 |
| T11 | 数据保留 | 造 3 天前的非必要数据，跑清理任务 | 到期数据删除、必要数据完整、审计有记录 |
| T12 | 注销 | 注册→建组→点赞→注销 | 矩阵各项按 U3.2 处理；联邦凭证即刻失效 |
| T13 | 上报与提速收录 | 客户端上报库外插件 → 管理端提速框收录 | 分钟级入库并出现在下发数据 |

## U7. ADR 增补

| 决策 | 结论 | 理由 |
|---|---|---|
| LB 退出 | 冻结快照 → 独立源 + 双侧提醒 | 数据不丢、用户知情、状态机统一 |
| 混合版本 | min 协议 + 未知字段忽略 + 兼容窗口 | 滚动升级/回滚的前提 |
| 收缩迁移 | 延迟一个版本周期 | 回滚安全线 |
| 密钥轮换 | 取消自动轮换，手动更换 | 用户指示；风险已登记 |
| 时钟 | 宿主机 NTP + 应用自检 + ±60s skew | 容器共享宿主时钟，自检兜底 |
