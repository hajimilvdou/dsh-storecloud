## S7. 安全监控页（管理端独立页面）

### S7.1 监控面板指标（首页面包式总览，一眼看全）

| 分组 | 指标 |
|---|---|
| 用户 | **注册用户数**（GitHub 登录）、**非注册活跃设备数**（匿名会话指纹去重，近 7 天）、今日新增注册 |
| 内容 | **插件总数**（在架/已拉黑分列）、**组总数**（已发布/待审/已下架分列） |
| 问题插件 | **系统扫描命中数**（L1/L2 风险标签、L3 队列）＋ **用户举报数**（待处置/已处置）——两个来源**分开显示**，不混算 |
| 服务健康 | API 请求量与错误率（5min/1h）、同步任务状态、GitHub token 池余量、扫描队列长度 |
| 安全事件 | 限流触发次数（Top IP 榜）、登录失败爆破尝试数、拉黑执行次数、异常下载峰值告警 |

### S7.2 告警
- 阈值可配置（配置中心 `alert.*`）：错误率、限流突增、扫描连续失败、token 余量低 → webhook 推送（飞书/钉钉/邮件）；
- 监控页数据全部来自既有日志/计数表聚合，**不引入重型 APM**，保持 2C4G 单机可跑。

## S8. 防护体系（防刷赞 / 防爆破 / 防匿名伪造）

### S8.1 防恶意刷赞（点赞可信度）
| 层 | 措施 |
|---|---|
| 硬约束 | 唯一索引（user+target），点赞必须 GitHub 登录 |
| 行为风控 | 同 IP 多账号集中点赞、注册即赞、高频切换点赞 → 进风控队列，**点赞计为"待确认"不计入排行**，人工/规则复核后生效或清除 |
| 权重 | 排行榜可使用"账号年龄加权"（新注册账号点赞权重低），权重参数配置中心可调 |

### S8.2 防爆破与恶意行为
- OAuth 回调与登录接口：按 IP 限流 + 连续失败指数退避 + 临时封禁；
- 所有写接口：用户 + IP **双维度限流**；
- 管理端：独立管理员凭证 + 全操作审计（v3 已有），管理端登录加二次确认（如 TOTP，可选配置）。

### S8.3 防"仿造未登录用户"刷接口
匿名通道（安装计数、数据下载）是唯一的无登录入口，加固：
1. **匿名会话凭证**：客户端首次请求换取短期匿名 token（绑定客户端生成的安装实例 ID），无 token 的匿名写请求直接拒绝——纯脚本无法零成本伪造；
2. 安装计数在匿名 token 上再做**窗口去重**（同 token 同目标 1h 内只计 1 次）；
3. 读接口按 IP 全局限流；异常流量模式（单 IP 拉全量 JSON 高频重复）自动降速/封禁；
4. 签名与校验沿用 v3 分发完整性方案，防止中间人篡改下发内容。

## S9. 近 7 天下载量与多维度排序

### S9.1 数据
- 下载计数按天聚合，产出 `downloads_7d`（滚动 7 天窗口）随数据通道下发；
- **插件卡与组卡统一标注"📥 近 7 天下载 N"**，与 ⭐（GitHub）、👍（本站赞）并列但语义独立。

### S9.2 排序选择（本地排序，切换零网络）
- 插件搜索页排序项：**默认综合 / ⭐星数 / 👍赞数 / 📥近7天下载量**；
- 组搜索页排序项：**默认综合 / 👍赞数 / 📥近7天下载量**；
- 排序控件为分段选择器，选择记忆到本地设置。

## S10. 云端安装清单与跨设备一键恢复（登录用户专属）

### S10.1 数据
- 登录用户的每次安装/卸载（插件或组）**实时上行**到服务器 `user_installs`（user_id、类型、目标、版本、来源组、时间）；
- 与本地台账（v3.1 S2）双向：本地是操作事实，云端是同步副本；卸载即云端移除。

### S10.2 新机器恢复流程（"我的"页功能区）
```
[☁️ 从云端恢复我的插件]（登录后可见）
  → 拉取该账号云端清单
  → 两个动作：
    ① 一键全部恢复（走标准确认清单 → 逐个安装）
    ② 搜索选择恢复：搜索栏过滤自己历史装过的插件/组，
       勾选部分安装（不必全量）
```
- 恢复的组自动沿用订阅语义（整组恢复=恢复订阅）；
- 未登录用户无此入口，提示"登录 GitHub 后可跨设备同步"。

## S11. 建组双源选择器

创建/编辑组合时，成员选择分**两个独立来源，各自带搜索栏**：

| 来源 | 内容 | 规则 |
|---|---|---|
| **A. 我已安装的插件** | 读本地台账 ∩ 服务器库（匹配成功才可加入组） | 库外插件（自己写的/未收录的）灰显不可选，旁挂"上报收录"引导（复用 v3.1 上报通道） |
| **B. 全库插件** | 完整插件索引 | 可正常选择**未安装**的插件，无需先装 |

- 两区可搜索、分开陈列；下方常驻"已选清单"（可排序/移除）；
- 组内成员仅存 `包名+版本` 弱引用（v2 规则不变）。

## S12. 配置 / API / ADR 增补

**配置新增**：`alert.*`（告警阈值与 webhook）、`rank.like_age_weight`、`anon.token_ttl`、`sort.default`。
**API 新增（登录）**：`GET/PUT /api/v1/me/installs`（云端清单读写）、`POST /api/v1/anon-token`（匿名会话凭证）。
**ADR**：

| 决策 | 结论 | 理由 |
|---|---|---|
| 刷赞处置 | 先隔离（待确认）后复核，不直接删 | 防误伤真实用户 |
| 匿名写接口 | 短期匿名 token 门槛 | 零成本伪造是刷量之源 |
| 云端清单 | 只存登录用户，卸载即删 | 最小化服务端持有数据 |
| 排序计算 | 全部本地 | 数据已下发，零网络、离线可用 |
| 库外插件入组 | 禁止，引导上报 | 组要对所有用户可安装，成员必须在库 |
