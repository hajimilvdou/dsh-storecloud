## 1. 设计总则（继承 v2，新增第 6 条）

1. 读路径本地化；2. 写路径实时化；3. 一切参数可配；4. 灵巧优先；5. 协议版本化；
6. **【v3 新增】UI 环境自适应**：同一套业务逻辑，按运行环境自动切换呈现形态（WebUI 内嵌 / 浏览器地址模式），业务层不感知 UI 差异。

## 2. 系统架构与数据流【v3 更新】

```
GitHub API ──定时增量──▶ 服务器：sync（抓取+提取+⭐星数快照）→ feed / write / auth / admin
                                │ manifest 心跳（版本比对，变了才拉）
                                ▼
                     dsh 插件（本地）
                ┌────────────────────────────┐
                │ 业务核心（环境无关）：本地索引/搜索/ │
                │ 榜单/组/点赞/公告/安装             │
                ├────────────────────────────┤
                │ UIAdapter 层（环境探测+渲染策略）   │
                │  · WebUI 模式：漂浮球+面板窗口      │
                │  · 地址模式：本地端口+浏览器打开    │
                └────────────────────────────┘
```

通道不变：插件数据通道（含星数与趋势榜）+ 组数据通道（默认 30 min，可配）。

## 3. 用户与认证（继承 v2，无变更）

GitHub OAuth 唯一登录；无头像；匿名可搜索/浏览/安装，登录才能建组/点赞/举报；每用户组上限 3（可配）。

---

## 4. 插件内容精确提取管线【v3 更新：抓取层补充星数快照】

五级管线（抓取→解析→归一化→质量评分→人工覆盖）不变，抓取层增加：

**⭐ 星数历史快照**
- 每次同步记录 `(repo, 快照日期, stars)`，**每日至少一个快照点**；
- 用途：计算"日增星数"= 当日快照 − 前一快照；新收录仓库首日标记 `new`，不参与增量排行或单独展示（策略可配置）；
- 快照保留窗口可配置（默认 90 天滚动），趋势榜只依赖最近两点，历史用于管理端图表。

## 7A. 星数趋势榜与双指标分离【v3 新增】

### 7A.1 今日星增 Top 20（Trending）

- 口径：`stars_delta_day` 降序取前 20（条数可配置，默认 20）；
- 生成方：**服务器**（依赖全量快照，客户端不自己算）；
- 下发：随插件数据通道到本地，**展示零网络**；
- 展示位置：搜索页顶部横滑区 + 独立"趋势"页（纵向列表）；
- **装不下就滑动**：横滑区一次露出 3~4 张卡，其余滑动；趋势页纵向滚动；固定就 20 条，不做"加载更多"；
- 每条必带：**排名、名称、简介（提取管线产出，2 行截断）、⭐ 当前星数、📈 日增数、来源徽标、安装按钮**。

### 7A.2 双指标分离原则（硬规则）

| 指标 | 含义 | 来源 | 图标/色 | 可互动 |
|---|---|---|---|---|
| ⭐ Stars | GitHub 收藏星数 | GitHub API（只读镜像） | 星形 / 金色 | 否（点击跳 GitHub） |
| 👍 Likes | 本站点赞 | 本站用户（登录） | 拇指 / 品牌色 | 是（登录后） |

- 两指标**永不合并、永不换算、永不互相影响**；
- 卡片上两者并列但视觉分离（图标、颜色、tooltip 文案明确："GitHub 星数" vs "本站点赞"）；
- 排序各自独立：趋势榜只按 stars_delta；热度榜只按 likes/downloads；不做混合分。

## 7B. 多 UI 适配与首启引导【v3 新增】

### 7B.1 UIAdapter 抽象

- 启动时探测运行环境能力：`webui`（可注入 DOM）/ `cli` / `headless` 等；
- 业务核心只调 UIAdapter 的统一接口（`mount / notify / openPanel / badge`），**环境差异收敛在适配层**——未来新 UI 类型只加一个 Adapter，不动业务。

### 7B.2 两种呈现模式

| 模式 | 触发条件 | 形态 |
|---|---|---|
| **WebUI 模式** | 探测到 dsh WebUI | 右下角漂浮球 ↔ 点击展开面板窗口 |
| **地址模式** | 无 WebUI（CLI / headless 等） | 插件内嵌轻量本地页面，绑定 `127.0.0.1:{port}`（端口可配），用户用浏览器访问 |

地址模式下功能与 WebUI 面板**完全一致**（同一套 UI 组件，两个挂载点）。

### 7B.3 前三次首启引导（仅非 WebUI 环境）

```
启动插件（非 WebUI 环境）
  → 本地记录 launch_count（0/1/2 → 本次为前三次之一）
  → 自动打开浏览器访问 http://127.0.0.1:{port}
  → 页面顶部常驻引导条：
    "已从本地服务打开本页面。若不希望每次自动弹出，点击 [不再自动打开]。
     之后可随时在浏览器访问 http://127.0.0.1:{port} 使用。"
  → 用户点 [不再自动打开] → 写入本地设置 → 此后永不自动弹，仅日志提示地址
  → 前三次自然用完后，同样转入"不自动弹"状态
  → WebUI 环境无此流程：首次仅在漂浮球上显示一次引导气泡
```

- `launch_count`、`auto_open` 均为本地设置；引导文案与"前三次"次数做进配置（`onboarding.auto_open_times`，默认 3）。

### 7B.4 窗口能力（WebUI 模式）

- **可调大小**：拖拽窗口右下/边缘，最小 360×480、最大 720×900（上下限可配置），尺寸记忆到本地；
- **明暗主题**：跟随系统 + 手动切换（浅色/深色），CSS 变量实现，选择记忆到本地；
- 位置记忆、收纳成小球、Esc 关闭、面板内快捷键（`/` 聚焦搜索）。

## 10. 生产级安全（继承 v2，补充一条）

- 地址模式本地页面：**仅绑定 127.0.0.1**，校验来源，不暴露局域网；本地端口访问与写操作凭证隔离（写操作仍需登录态）。

---

## 11. 灵巧性约束（继承 v2，补充）

- 面板窗口缩放/主题切换 < 16ms 重绘（CSS 变量 + transform，禁大面积重排）；
- 地址模式页面与 WebUI 面板**共享同一构建产物**，不为两种模式维护两套代码。

---

## 12. 扩展性预留（继承 v2，补充）

- UIAdapter 即为最大扩展点：未来 TUI、IDE 内嵌、移动端 Web 均可新增 Adapter 接入；
- 趋势榜口径抽象为 `RankingProvider`，未来可加"周增榜""新星榜"仅增配置。

## 13. API 概览【v3 更新】

读接口不变（趋势榜数据已并入插件数据通道，无新增读接口）；写接口不变；管理端新增：趋势榜口径配置、星数快照查询（图表数据源）。

## 14. 关键决策记录（ADR 增补）

| 决策 | 结论 | 理由 |
|---|---|---|
| 趋势榜计算方 | 服务器算好下发 | 依赖全量快照；客户端零成本、离线可看 |
| 双指标 | ⭐ 与 👍 严格分离 | 语义不同（外部认可 vs 站内推荐），混淆会误导新手 |
| Top 20 展示 | 固定 20 条，滑动浏览，带简介 | 信息密度与性能平衡；简介是新手决策关键 |
| 非 WebUI 形态 | 地址模式（127.0.0.1）+ 前三次自动打开 + 可永久关闭 | 无 WebUI 也要有完整功能；自动弹仅做引导，尊重用户选择 |
| 两端 UI | 一套组件两个挂载点 | 防止双倍维护 |

## 15. 界面设计规格（客户端 + 服务器管理端）

> 高保真可交互原型见 **`dsh-store-ui-prototype.html`**（明暗主题、横滑 Top 20、地址模式引导条、管理端各页均有演示）。以下为设计规格，施工以原型为视觉基准。

### 15.1 设计原则

- **轻**：所有界面三秒内可完成核心动作（搜→装）；
- **清**：双指标分离、来源徽标、兼容版本三要素每张卡片必现；
- **一致**：两种 UI 模式同一组件库；管理端与客户端同一设计语言。

### 15.2 客户端（插件面板）

**漂浮球**：56px 圆形，品牌渐变底 + 白色拼图图标；右下象限悬浮，可拖拽任意位置并边缘吸附；未读公告时右上角红色叹号角标；hover 放大 1.08 倍并显 tooltip。

**面板窗口**（默认 400×600，可调）：

```
┌──────────────────────────────┐
│ 🧩 插件商城      🔍搜索…  ☾/☀ 👤 │ ← 顶栏：品牌/搜索/主题/登录态
├──────────────────────────────┤
│ [搜索] [趋势🔥] [组合] [我的]    │ ← Tab 栏
├──────────────────────────────┤
│ 📈 今日星增 Top 20  (横滑 →)     │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐   │
│ │#1  │ │#2  │ │#3  │ │ …  │   │ ← 横滑卡片：名称+简介2行+
│ └────┘ └────┘ └────┘ └────┘   │   ⭐/📈/👍/安装
├──────────────────────────────┤
│ 搜索结果/列表（纵向滚动）         │
│ ┌──────────────────────────┐ │
│ │ 名称  [来源徽标] [兼容版本]  │ │
│ │ 简介（2行截断）…            │ │
│ │ ⭐1.2k(金色) 👍86(品牌色) 📈+57│ │ ← 双指标并列但视觉分离
│ │              [一键安装]    │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- **地址模式引导条**（仅非 WebUI、且未关闭自动弹出时）：顶部通栏，含说明文案 + [不再自动打开] 按钮 + 手动访问地址；
- **公告**：叹号点击 → 抽屉式公告面板（最新置顶 + 历史列表）；
- **我的**：已装清单、我的组（显示 `已用 2/3` 配额）、我的点赞、设置（主题/窗口/通知/服务地址）。

### 15.3 服务器管理端

左侧导航 + 顶栏（管理员名/登出）的经典后台布局，六个功能页：

| 页面 | 核心内容 |
|---|---|
| 仪表盘 | 四张统计卡（插件总数/注册用户/组合数/今日星增冠军）、同步状态（上次 GitHub 同步、token 余量）、待办队列（needs_review / 举报数） |
| 插件库 | 可检索表格（名称/来源/⭐/📈/质量分/状态），行内进入"人工覆盖"编辑 |
| 组合审核 | pending 队列、一键通过/下架、敏感词命中高亮 |
| 用户管理 | 用户列表（login/姓名/注册时间/组数/状态），禁用/恢复 |
| 公告管理 | 发布表单（版本号/标题/分级/正文）+ 历史公告（可下线）——**更新提醒唯一入口** |
| 配置中心 | 分组表单（同步/榜单/引导/UI/功能开关），保存即生效并写入审计 |

设计细节（栅格、色板、组件状态、暗色模式映射）以原型文件为准。
